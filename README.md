# sporty

PWA с планом тренировок к 70.3 Ironman (лето 2027) для двух атлетов: общий каркас и персональные модули.

**Сайт:** https://72-56-96-233.sslip.io. Ссылка сразу под атлета: `?a=nikita` или `?a=vanya`.

Контекст и требования лежат в [docs/context.md](docs/context.md).

## Как править план

Весь план находится в одном файле — [`src/data/plan.yaml`](src/data/plan.yaml). Интерфейс только читает его.

- `workouts` — библиотека тренировок: текст, сегменты для графика, «зачем», личные заметки.
- `templates` — шаблоны недели: `together` — тренируемся вместе, `nikita`/`vanya` — личные модули.
- `weeks` — календарь: какая неделя идёт по какому шаблону, `kind: deload` — разгрузка.
- `events` — поездки и гонка: на эти даты заменяют расписание.
- `milestones` — точки на таймлайне, расписание не меняют.

После правки `npm run validate` проверяет, что ссылки и даты в порядке. Push в `main` сам собирает и выкладывает сайт (GitHub Actions → rsync на сервер).

## Разработка

```sh
npm install
npm run dev       # http://localhost:5173
npm run build     # validate + сборка в dist/
```

Стек: Vite + Preact, vite-plugin-pwa (офлайн, установка на телефон), план в YAML.
